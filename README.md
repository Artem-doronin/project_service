### 📦 Project Service
## 📄 Описание
Project Service — микросервис, отвечающий за управление стартап-проектами. Он включает в себя:
- Создание и редактирование карточек проектов.
- Получение списка проектов и деталей по id.
- Отслеживание статуса проекта.
- Этот сервис связывает проекты с их владельцами и постами.

## ⚙️ Технологии
## Основные технологии
- Java 17: современный язык программирования для создания надежных приложений.
- Spring Boot 3.x: фреймворк для упрощения разработки приложений на Java.
## Базы данных
- PostgreSQL: реляционная база данных для хранения проектов.
- Liquibase: инструмент для управления версиями базы данных.
## Взаимодействие между микросервисами
- Kafka: публикация событий создания/обновления проекта.
- OpenFeign: клиент для взаимодействия с User Service и Post Service.
## Тестирование
JUnit 5, Mockito, Testcontainers.
## Дополнительные инструменты
Lombok, MapStruct, Springdoc OpenAPI, Docker, Slf4j.

## 🔗 Связанные сервисы
- User Service: для связи проекта с владельцем.
- Post Service: для связи постов с проектом.
- Payment Service: для монетизации проектов.
- Analytics Service: для сбора статистики по проектам.
